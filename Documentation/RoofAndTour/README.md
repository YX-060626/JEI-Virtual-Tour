# 屋顶与第一 / 第三人称漫游

打开 `Assets/Scenes/JEI_Floor_Structure.unity`，点击 Play，默认进入一楼门厅的第一人称视角。

| 操作 | 按键 |
|---|---|
| 行走 / 转向 | WASD / 鼠标 |
| 跳跃 | Space 空格（着地时） |
| 步行 / 跑步切换 | Shift（按一次切换） |
| 第一、第三人称切换 | V |
| 漫游、建筑总览切换 | Tab |
| 释放鼠标 / 重新控制 | Esc / 点击 Game 画面 |
| 总览中单独显示楼层 | 1 / 2 / 3 |
| 总览中显示整栋 | 0 |
| 总览中显示、隐藏屋顶 | R |
| 总览中环绕 / 缩放 | 鼠标拖动 / 滚轮 |

屋顶采用原有结构材质，楼板厚 0.30 m，底部 +10.50 m、顶部 +10.80 m，外缘和庭院四周设 0.70 m 高基础女儿墙。中央庭院保留 7.80 × 6.40 m 开口，其余三楼空间封顶。此版没有屋顶上行楼梯或屋顶装饰。

第三人称共用同一个 CharacterController 和相机，显示有关节的卡通人物；靠近墙体时相机自动收近，过近时隐藏角色以免挡住画面。角色已加入走路、跑步和跳跃姿态，详见 [角色与动作说明](../CharacterMovement/README.md)。

楼层单独查看时会自动隐藏屋顶；进入漫游时恢复完整建筑与屋顶。隐藏只影响渲染，不影响碰撞。

`Geometry_Verification.txt`、`Runtime_Verification.txt` 记录覆盖、通行、相机避障和模式切换结果。PNG 为 Unity 实际场景 / 运行相机预览。
